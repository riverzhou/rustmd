# rustmd 1.12.0

这一版给 CSV 预览加上**表头点击排序**：读数据表时不用改文件、不用导出到 Excel，
点一下表头就能按数值、日期或文本查看；排序只发生在渲染区，原文完全不动，随时可以
一键回到原始行顺序。

## 新增

- **点击表头排序**：每次点击在「升序 → 降序 → 原始顺序」之间循环。当前排序的列会
  显示方向箭头和高亮，表头也带有 `aria-sort` 状态。
- **「原始顺序」按钮**：排序后出现在 CSV 卡片头部，随时一键恢复源文件的行顺序。
- **按列类型比较**：数字、货币、百分比、日期、布尔值按实际值排序；普通文本按系统
  本地化的自然顺序排序，`item2` 会排在 `item10` 前面。空值/缺失值始终排在最后，
  相等行保持源文件中的先后顺序。
- 键盘可操作：表头是真正的按钮，Tab 聚焦后可用 Enter / Space 排序，中英文提示同步。

## 只改渲染区

- 排序只重排预览里已经渲染的行；编辑器内容、磁盘文件、保存状态都不受影响。
- 同一篇笔记内，编辑、切换主题或语言触发的预览重渲染会保留当前排序；切换笔记会
  自动回到原始顺序，排序不会“串”到别的 CSV。
- PNG / PDF / 独立 HTML 导出仍按原文顺序生成静态表格，导出文件里不会出现无效的
  排序按钮。

## 测试

- 新增 CSV 排序纯函数单测：数值/货币/百分比/日期/布尔比较、自然文本顺序、缺失值
  置底、稳定排序、不修改源数组（前端单测共 72 个）。
- 真实 WebView E2E 自测新增：三态循环、重置按钮、TXT 不出现排序控件、导出 HTML
  保持静态表格；`npm run check`、`npm run selftest` 与报告校验均通过。

## 升级说明

- 没有文件格式变化，直接覆盖安装即可；CSV 文件不会被排序改写。
- 包管理器清单会在 GitHub Release 资产发布后刷新到 1.12.0；届时可继续用 winget /
  Scoop / Homebrew 安装。
