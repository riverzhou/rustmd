# Code of conduct

## Our pledge

We want rustmd to be a welcoming project for anyone who uses, tests or contributes to it,
regardless of experience, language, background or identity.

## Expected behavior

- Be respectful and specific. Critique ideas and code, not people.
- Assume good faith; ask before rewriting someone else's work.
- Keep discussions on topic. Bug reports should contain reproducible steps; feature
  requests should describe the workflow they solve.
- Respect the project's constraints (plain files, offline-friendly, no account) when
  discussing scope.
- Accept that maintainer time is limited: an unanswered issue is not a rejection.

## Unacceptable behavior

- Harassment, insults, threats, sexualized language or imagery, and personal attacks.
- Discriminatory comments or jokes about protected characteristics.
- Publishing someone's private information without permission (including note contents,
  paths, email addresses or screenshots that reveal them).
- Spam, repeated off-topic self-promotion, or deliberately derailing threads.
- Opening public issues for security vulnerabilities instead of using the private flow in
  [`.github/SECURITY.md`](.github/SECURITY.md).

## Scope

This applies to issues, pull requests, discussions, reviews and any project space where
someone represents rustmd.

## Enforcement

Report unacceptable behavior to the maintainer at `riverzhou2000@163.com`. Reports are
handled confidentially. The maintainer may edit or remove content and may warn, temporarily
block or permanently ban participants. Good-faith reports will never be punished.

## Attribution

This code of conduct is intentionally short; it is informed by the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
